
## Поддерживаемые алгоритмы

- Эллиптические кривые и ЭП (ГОСТ Р 34.10-2001 и ГОСТ Р 34.10-2012)
    - Функция согласования ключа (VKO)
    - Конвертация точек кривой (Вейерштрасс <-> Скрученный Эдвардс)
    - Встроено множество кривых (ТК-26, КриптоПро, тестовые)
- Хэш-функция ГОСТ Р 34.11-94
    - Поддерживает HMAC и PBKDF2
- Шифр "Кузнечик" (ГОСТ Р 34.12-2015)
- Шифр "Магма" (ГОСТ Р 34.12-2015)
    - Поддерживает старую версию из ГОСТ 28147-89
    - Встроено множество S-Box (КриптоПро, Держспецзв'язку, тестовые и т.д)
- Хэш-функция "Стрибог" (ГОСТ Р 34.11-2012)
    - Поддерживает HMAC, PBKDF2 (512 бит), `kdf_gostr3411_2012_256`, `kdf_tree_gostr3411_2012_256` и CPKDF

## Поддерживаемые режимы шифров

- Режим простой замены с зацеплением (CBC)
- Режим гаммирования с обратной связью по шифртексту (CFB)
- Режим гаммирования (CTR)
    - Поддерживает версию для ГОСТ 28147-89 (CNT), а также гаммирование с преобразованием ключа (CTR-ACPKM)
- Режим простой замены (ECB)
- Режим выработки имитовставки (MAC)
    - Поддерживает версию для ГОСТ 28147-89, а также выработку имитовставки с преобразованием ключа (OMAC-ACPKM)
- Режим шифрования с имитозащитой и ассоциированными данными (MGM)
- Режим гаммирования с обратной связью по выходу (OFB)
- Обёртка ключей:
    - Обёртка ключей с использованием функций KExp15/KImp15
    - Обёртка ключей для ГОСТ 28147-89 (поддерживает CryptoPro KEK derivation)
